Quick start

This page takes you from a structure file to a table of interactions in a few minutes. The example is the structure 1AZM (human carbonic anhydrase II with the inhibitor acetazolamide, ligand name AZM, and a zinc ion), which you can download from the RCSB Protein Data Bank as 1AZM.pdb or 1AZM.cif.

In the graphical interface

  1. Start ligint from the applications menu (Linux), the Start menu (Windows) or with ligint-gui in a terminal.
  2. Click Open structure... (or press Ctrl+O, or drag the file onto the window) and choose 1AZM.pdb.
  3. The Ligand list now shows AZM A 262 (13 atoms). Ions and very small molecules (fewer than 6 atoms) are hidden unless you tick Also show ions and small molecules.
  4. Press Analyze. The ligand and the residues that touch it appear in the 3D view; the Interactions tab lists each interaction with its atoms and distance.
  5. Drag in the view to rotate, use the wheel to zoom, click a row of the table to highlight that interaction.
  6. File > Export interactions (CSV)... saves the table, File > Save image... saves the view as a PNG, and File > Copy command line copies the ligint command that reproduces the analysis.

The full description of the window is in The graphical interface.

On the command line

Without a ligand name, ligint lists the ligands of the file:

$ ligint 1AZM.pdb
Ligands (HETATM) present: AZM(1) ZN(1)

Give the name of a ligand to analyze it:

How to read it:

  • Each row of the table is one interaction: its type, whether it is favorable (+) or not (-, clashes and repulsions), the ligand atom, the protein atom and the distance in angstroms, and notes (angles, the water that mediates a bridge...).
  • The summaries count the interactions by type and by protein residue.
  • The last block lists the coordination sphere of the metals that the ligand touches. Here the ligand nitrogen and three histidines hold the zinc.

Useful variations:

ligint 1AZM.pdb AZM --csv > interactions.csv          the same table as CSV, for a spreadsheet or a script
ligint 1AZM.pdb AZM A 262                             only chain A, residue 262 (when the ligand appears several times)
ligint 1AZM.pdb AZM --no-water                        ignore water molecules (no water bridges)
ligint 1AZM.pdb AZM --fingerprint svg > figure.svg    the interaction fingerprint as a figure
ligint 1AZM.cif AZM                                   the same analysis from the mmCIF file

All the options are in the Command-line reference.

Where to get structures

Search by name or code at rcsb.org and download the PDB or PDBx/mmCIF file. Files from the archive are often compressed (.gz): decompress them first (gunzip 1abc.cif.gz). New entries of the Protein Data Bank will only be distributed as PDBx/mmCIF: see Input formats.

Things to know before trusting a result

  • Crystal structures do not contain hydrogens, so the donor and acceptor roles and the charges of the ligand are inferred from the geometry (for example, carboxylates are treated as anionic and aliphatic amines as cationic). An SDF or MOL2 file of the ligand can supply the exact chemistry: see Interactions and assumptions.
  • The results are geometric criteria applied to a model, not a measurement of binding. Validation and limits explains how they compare with another tool and where they are weak.
