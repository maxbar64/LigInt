ligint manual

ligint finds the non-covalent interactions between a small-molecule ligand and the protein around it in a structure file (PDB or PDBx/mmCIF): hydrogen bonds, salt bridges, hydrophobic contacts, pi-stacking, cation-pi, halogen bonds, metal coordination and water bridges, plus steric clashes and electrostatic repulsions. It can also summarize them as an interaction fingerprint: a table with one row per protein residue and one column per interaction class, drawn as a figure.

It comes as a command-line program (ligint) and a graphical interface (ligint-gui) that share the same analysis engine. The graphical interface shows the ligand and its surroundings in 3D, lists the interactions in tables, and writes, for every analysis, the command line that reproduces it outside the program.

Conventions

Commands are shown for a POSIX shell (bash, zsh); on Windows use the same options in a terminal where ligint.exe is in the PATH. Distances are in angstroms (A), angles in degrees. A ligand is a HETATM residue of the file; protein is everything else that is not water. Menu items and buttons of the graphical interface are written in bold.
